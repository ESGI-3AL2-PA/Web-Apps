## Data inventory this layer is written against

Verified against the entities in `apps/api/src/entities/` and `apps/auth-service/src/entities/`:

- **Account/identity** — email, password (argon2 hash), first name, last name, phone (optional), home
  address (free text), district assignment (`districtId`; districts carry GeoJSON boundaries), points
  balance, role, ban/verification flags.
- **Security** — TOTP secret + enabled flag; per-session refresh-token records storing **IP address**,
  **User-Agent**, and last-used timestamp.
- **Communications** — conversations and messages (text, plus **image / audio / file** media stored via
  MinIO), read receipts.
- **Contracts** — provider/beneficiary ids, price, Documenso document id, signing URLs, signature status,
  dispute reason; **signed PDFs generated by Documenso embed name/address/price**.
- **Ledger** — points transactions (credit/debit/transfer, amount, ref).
- **Community content** — listings (with images), events (+ registrants), votes (+ per-user responses),
  incidents (+ photos, status history), notifications.

> **Verify-if-changed:** the audit found **no continuous/live GPS geolocation** — location is derived
> from the stored address and a district boundary (GeoJSON) match. If real-time geolocation is ever
> added, the privacy policy and RoPA must be updated (it is likely a new purpose + possibly consent).
